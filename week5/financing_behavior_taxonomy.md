## 2. 分类详情

### A. 增资（PE/VC 溢价进入）— 60条，8/8公司

**招股书典型表述**:
```
"本次股票发行价格为4.48元/股，共发行普通股530.00万股，募集资金总额为2,374.40万元。"
——三协电机 2022年定向发行

"增资价格为22.42元/注册资本...赛格高技术认缴462.8571万元、上汽科技认缴51.4286万元"
——黄山谷捷 A轮增资
```

**子类型**:

| 子类型 | 特征 | 示例 | 提取难点 |
|------|------|------|------|
| A1. 定向发行（单一PE） | 标准格式：价格+数量+总额 | 友升A/B轮 | 低，正则可覆盖 |
| A2. 定向发行（多PE合计未拆分） | 一个金额对应多个主体 | 三协电机2022定增 | ⚠ 不能反推 |
| A3. 定向发行（员工激励） | 多名自然人共一个金额 | 三协电机2023 15人 | 名单需拆分 |
| A4. 溢价增资（有估值） | price × shares → 可回算估值 | 黄山谷捷A轮 | PE/VC判断 |
| A5. 同比例增资 | 原股东按比例 | 深圳三协子公司 | 非PE/VC事件 |

**提取字段**: subscription_date, subscriber_name, shares_subscribed, amount_subscribed, price_per_share, pre_money_valuation, post_money_valuation

**当前自动准确率**: ~50%（漏在A2合计拆分、A3名单拆分、A5误判为非PE）

### B. 整体变更（股改）— ~24条，5/8公司

**招股书典型表述**:
```
"有限公司将经审计净资产额45,010,412.64元按1.1253:1的比例折成4,000万股"
——云汉芯城 2015年股改

"以2021年7月31日为股改基准日，净资产按比例折股"
——赛分科技 2021年股改
```

**特征**: 
- 关键词："整体变更"、"折股"、"股改基准日"、"发起人"
- 不涉及外部现金流入，是净资产折股
- 所有老股东按原比例转换为股份公司股东

**提取字段**: subscription_date, subscriber_name (发起人), shares_subscribed (折股数), event_context="整体变更"

**当前自动准确率**: ~17%（4条正确，~20条误标为"其他"）
**为什么规则会漏**: "整体变更"不包含"增资"关键词，正则的增资模式匹配不到

### C. 增资及股权转让（混合事件）— 17条，4/8公司

**招股书典型表述**:
```
"2021年增资：赛格高技术增资的同时，黄山供销集团将其部分股权转让给..."
——黄山谷捷
```

**特征**:
- 同一时间点同时发生增资和转让
- 需要拆分为两条记录（一条增资 + 一条转让）
- 或者区分哪些是增资进入、哪些是转让进入

**提取难点**: 时间线拆分、增资vs转让的金额分配

### D. 股权转让 — 7条，4/8公司

**子类型**:

| 子类型 | 特征 | 示例 |
|------|------|------|
| D1. 同一控制下转让 | 家族内部/关联方 | 黄山谷捷 3条 |
| D2. 代持还原 | "代持已解除" | 三协电机/星图测控 |
| D3. 零对价转让 | 转让价=0 | 赛分科技 |
| D4. 外部转让 | 引入新股东 | 影石创新 |

**提取字段**: transfer_date, transferor_name, transferee_name, shares_transferred, transfer_amount, transfer_type

**当前自动准确率**: ~15%（零对价/代持还原属于"不披露金额"，代码误判为漏提取）

### E. 设立（公司成立）— 7条，4/8公司

**招股书典型表述**:
```
"2002年11月07日，常州三协电机电器有限公司成立。"
——三协电机（未披露具体出资额）

"有限公司设立时注册资本500万元，其中..."
——友升股份（有完整出资明细）
```

**提取难点**:
- 设立时的出资额不一定在招股书正文（三协电机需查公开转让说明书）
- 时间过早（2002年）可能与后续事件格式不一致

### F. 资本公积转增 — ~3条

**招股书典型表述**:
```
"以股票发行溢价所形成的资本公积向全体股东每10股转增3.80股"
——三协电机 2023年权益分派
```

**关键判断**: 这不是外部融资事件！amount_subscribed=0，shares来自内部权益调整。

### G. 吸收合并 — ~3条（黄山谷捷特有）

```
"谷捷有限吸收合并昆山谷捷...合并后注册资本变更为1,200万元"
```

### H. VIE搭建/拆除 — ~4条（影石创新特有）

```
"搭建红筹架构"→"拆除红筹架构"
```

**特征**: 融资历史分散在"架构搭建"和"架构拆除"两段，章节定位传统方法失效。

## 3. 招股书中的表述模式库

从8家公司原文中提取的典型表述模式：

| 模式 | 正则模板 | 适用类型 |
|------|------|:--:|
| "发行价格为X元/股，共发行普通股X万股，募集资金总额为X万元" | 定向发行标准式 | A1 |
| "已收到A、B缴纳的出资款X万元" | 验资报告合计式 | A2⚠️ |
| "拟发行价格X元/股，拟发行普通股X万股" | 拟发行公告式 | A3 |
| "X年X月X日，有限公司整体变更设立股份有限公司" | 股改标准式 | B |
| "将经审计净资产X元按X:1比例折成X万股" | 股改折股式 | B |
| "每10股转增X股" | 转增式 | F |
| "股权代持已解除" | 代持解除式 | D2 |

## 4. 下一步：按类型设计提取 prompt

每种类型一个 prompt，不是通用 prompt：

```
prompt_a1_定向发行标准式.txt  → price + shares + amount 三字段完整
prompt_a2_多主体合计式.txt    → 识别"合计" → amount留空
prompt_a3_员工激励名单式.txt  → 15人名单拆分为15行
prompt_b_股改.txt             → 净资产折股 + 发起人列表
prompt_d_股权转让.txt         → 转让方/受让方/对价
prompt_f_资本公积转增.txt     → 非外部融资判断
```

**三协电机优先级**: A2（修复 subscription_flow 合计问题）→ F（新增转增事件）→ A3（拆分15人名单，目前0条）
