# Week 8 Auto-vs-Gold 匹配规范

## 一对一约束

一条 Auto 最多匹配一条 Gold，一条 Gold 也最多匹配一条 Auto。重复候选中只有一条可以成为 TP，其余必须计为 FP。匹配使用确定性的最大匹配，固定输入重复运行必须得到相同配对。

## 事件级兼容条件

1. 股票代码必须完全一致；
2. 统一事件类型必须一致；Gold 为“增资及股权转让”时，允许 Auto 的“增资”或“股权转让”作为组成部分匹配；
3. Gold 披露到日时，Auto 必须为同一日；
4. Gold 只披露到月时，Auto 的同月日期可以匹配；
5. Gold 只披露到年时，Auto 的同年日期可以匹配；
6. Auto 日期缺失或无效时不能成为 TP。

优先级为精确日、同月、同年；同等条件按稳定ID排序。所有匹配输出日期和类型的匹配理由。

## 指标

`Precision = TP / (TP + FP)`，`Recall = TP / (TP + FN)`，`F1 = 2PR/(P+R)`。分母为零时写 `null/N/A`，不能写100%。指标按全样本、公司和事件类型分别输出。

## 证据追溯

TP保存Auto ID和Gold ID；FP保留Auto原始证据；FN保留Gold原始证据。评价程序不得改写原文证据。
