# 盲测 Gold 标注指引

**目标**：为 688795 摩尔线程、688802 沐曦股份各生成一份事件级 Gold，供 Week 10 与冻结规则输出对比。

## 1. 数据源

只使用以下两个文件（均在仓库内）：

```text
week1/review/688795_摩尔线程_招股书_正式稿_20251128.md   (39,084 行)
week1/review/688802_沐曦股份_招股书_正式稿_20251211.md   (41,533 行)
```

两份 Markdown 都有 `## 第N页` 页码标记（688795 共 466 个、688802 共 523 个），可按页定位证据。

## 2. 重点章节定位

摩尔线程（688795）：

```bash
rg -n '三、发行人报告期内的股本和股东变化情况|（二）发行人报告期内的股本和股东变化' \
  week1/review/688795_摩尔线程_招股书_正式稿_20251128.md
# 主要区间约在 4438—4712 行，需结合前面“发行人基本情况”章节交叉核对
```

沐曦股份（688802）：

```bash
rg -n '二、发行人设立情况和报告期内的股本、股东变化情况|（一）发行人设立情况|（二）报告期内的股本和股东变化情况' \
  week1/review/688802_沐曦股份_招股书_正式稿_20251211.md
# 主要区间约在 4375—5267 行
```

IPO 申报/受理/问询状态事件通常在“本次发行概况”“发行上市安排”或招股书日期相关段落，按 `status_event` 枚举逐条记录。

## 3. 日期规则

- 原文只有“2022 年 12 月” → `event_date=2022-12`，`date_type=month`；
- 原文只有年份 → `date_type=year`；
- 由上下文推算（如“报告期第一次增资”只能定位到某区间）→ `date_type=inferred` 并在 notes 说明推断依据；
- 优先取工商核准/变更日；只有协议日时取协议日并注明；
- 同一天多个连续工商变更分别成条。

## 4. 金额与估值规则

- 金额单位统一为“万元”，保留原币种字段；不做汇率换算；
- 招股书披露总金额就填总额，否则 `amount_disclosed=false`；
- 估值必须标 `投前` / `投后`；不能由“认购价格 × 股数”推算估值；
- 资本公积转增不是外部融资，金额留空。

## 5. 轮次规则

- 优先采用招股书原文口径，例如“第一次增资”“第二次增资”或明确的“A轮”“B轮”；
- 原文未披露轮次填 `未披露`；不得使用公开报道或市场俗称补轮次。

## 6. 证据与去重

- `evidence_text` 必须是原文逐字摘录，可以截断首尾，但不得改写或概括；
- 同一事件在“目录/章节列表”与正文重复出现时只记一条，notes 列明重复位置；
- 每条 Gold 必须能通过 `source_page` 回到原文。

## 7. 独立性要求

- 标注期间不得查看 `week6/auto_output*`、`run_md_pipeline.py` 输出或任何规则结果；
- 已有 `week1/outputs/*/融资历史.json` 是早期抽取结果，不得作为 Gold 依据；
- 标注完成后由第二人抽查（至少 30% 记录），确认后才可置为 `frozen`。
