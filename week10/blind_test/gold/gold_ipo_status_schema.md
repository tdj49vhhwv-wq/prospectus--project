# IPO 进程事件流 Gold 字段规范（辅助层）

**适用**：688795 摩尔线程、688802 沐曦股份盲测 Gold v1.0
**性质**：辅助事实层，记录招股书中披露的申报/受理/问询等状态事件；**不参与本次事件级 P/R/F1**，因为冻结规则当前不产出该事件类型。

## 1. 字段定义

| 字段 | 必填 | 格式 / 枚举 | 说明 |
|------|:--:|------|------|
| `blind_gold_id` | 是 | `BT-{stock_code}-{seq:03d}` | 盲测 Gold 唯一 ID |
| `stock_code` | 是 | `688795` / `688802` | 公司代码 |
| `company_name` | 是 | 文本 | 与 manifest 一致 |
| `status_event` | 是 | `申报` / `受理` / `问询` / `上会` / `注册` / `发行` / `上市` | 状态事件类型 |
| `status_date` | 是 | `YYYY-MM-DD` 或 `YYYY-MM` | 状态发生日期；原文未披露填 `未披露` |
| `source_file` | 是 | 文件名 | `week1/review/` 下对应 Markdown |
| `source_page` | 是 | `第N页` 或 `行区间` | 能回原文定位 |
| `evidence_text` | 是 | 原文逐字摘录 ≤ 500 字 | 不得概括、不得改写 |
| `annotator` | 是 | 姓名/标识 | 标注人 |
| `annotation_status` | 是 | `draft` / `reviewed` / `frozen` | 状态机 |
| `notes` | 否 | 文本 | 歧义、多轮问询说明 |

## 2. 标注规则

1. 一条记录 = 一个状态事件；多轮问询按时间顺序各记一条；
2. 状态以招股书正文披露为准，不引用交易所官网补充；
3. 招股书未披露的状态不标注，不填 `无`。

标注模板见 `gold_ipo_status_template.csv`。
