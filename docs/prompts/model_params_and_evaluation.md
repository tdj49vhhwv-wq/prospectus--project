# Prompt 实验记录 — 模型参数与评价

## 模型参数

| 参数 | 值 | 说明 |
|------|------|------|
| 模型 | Qwen-Max (通义千问) | 阿里云百炼平台 |
| Temperature | 0.0 | 最大化确定性，消除随机性 |
| Top-p | 1.0 | 不截断 |
| Max tokens | 4096 | 单次响应上限 |
| 调用方式 | 分模块（4次/公司） | 增资/转让/结构性事件/VIE |

## 分模块调用策略（v3最终版）

| 模块 | 覆盖类型 | 输入 | 输出 |
|------|---------|------|------|
| Module A | A1-A6 增资 | PE/VC章节文本 | 增资事件JSON |
| Module B | D1-D6 转让 | 历史沿革文本 | 转让事件JSON |
| Module C | B/C/E/F/G | 全文关键页 | 结构性事件JSON |
| Module D | H1-H9 VIE | 协议控制章节 | VIE事件JSON |

## 迭代记录

### v1 → v2（三协电机验证）

- v1 通用 prompt: 准确率 38%（3个致命错误）
  - A2 合计未拆分：15人合计1723万被当作每人1723万
  - F型转增误判：资本公积转增被识别为增资
  - 拟募集≠实际收到：计划金额被当作实缴金额
- v2 按类型修复: 准确率 100%
  - 增加"合计判断"指令
  - 增加"F型转增≠增资"规则
  - 增加"拟募集vs实缴"区分

### v2 → v3（架构优化）

- 单次全量调用: 准确率 67%（上下文过长导致遗漏）
- 分模块调用: 准确率 100%（每次聚焦一类，减少干扰）
