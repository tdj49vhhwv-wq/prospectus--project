# PE/VC 融资事件分类体系 — 最终验证版

**版本**: 3.0 (8家公司 × 7家合并MD逐事件验证)
**日期**: 2026-07-17
**验证方法**: 从7家公司合并MD（10-19页/家）逐事件提取 → 按10类型归类 → 不足类型从原始招股书补充

## 二、每种类型 2-4 个真实原文案例

### A. 增资（PE/VC进入）

**A1 标准定向发行（价格+数量+总额三字段完整）**

> 案例1: 赛分科技 2021-11 Pre-IPO轮
> "源峰磐赛认购1,571,815股，股份价格127.24元/股，认购金额20,000.00万元；珠海峦恒认购628,726股，认购金额8,000.00万元；高瓴祈睿认购628,726股，认购金额8,000.00万元。合计4,243,901股，54,000.00万元。"
> — 赛分科技 p59

> 案例2: 星图测控 2023-05 定向发行
> "本次股票发行股数为7,500,000股，每股价格为人民币6.30元，募集资金总额为47,250,000.00元。策星银河认购2,790,000股（1,757.70万元），策星逐日认购1,710,000股（1,077.30万元），幸福二期认购3,000,000股（1,890.00万元）。"
> — 星图测控 p42

**A2 多主体合计未拆分（一个金额对应多个主体，不能反推）**

> 案例1: 三协电机 2022-08 定向发行
> "经审验，截至2022年8月9日，公司已收到稳正景明、长泽创投缴纳的出资款2,374.40万元。"
> — 三协电机 p32
> ⚠ 处理: amount_subscribed=null, notes="PDF只披露合计，未单独披露各自金额"

> 案例2: 云汉芯城 A轮（从对赌表格反推）
> "A轮 力源信息、东方富海、芜湖富海" — MD p66
> ⚠ 单个投资者出资额未在MD文本中披露（在流程图中）

**A3 员工激励增资（低于公允价值，构成股份支付）**

> 案例: 三联锻造 2019-12
> "新增注册资本由新股东三联合伙以每股4.50元的价格认购，其中348万元计入注册资本，剩余1,218万元计入资本公积。"
> 公允价值7.15元/股，4.50 < 7.15 → 股份支付
> — 三联锻造 p35

**A4 溢价增资有估值**

> 案例1: 云汉芯城 C轮
> "上述增资和股权转让的每股价格约为29.13元，对应发行人整体投后估值约为13.5亿元。"
> — 云汉芯城 p56

> 案例2: 友升股份 Pre-IPO
> "本次增资作价为33.6323元/股，增资价格系综合参考发行人的经营状况、财务状况、发展预期等因素后由各方协商确定。"
> — 友升股份 p80

## 三、按类型设计提取 Prompt

### A 型 prompt: 增资事件提取

```
你是招股书PE/VC融资事件提取助手。请从以下招股书原文中，提取所有增资事件。

输出JSON格式:
{
  "events": [{
    "date": "YYYY-MM-DD",
    "type": "增资",
    "sub_type": "A1|A2|A3|A4|A5",
    "investors": [{"name": "", "amount": 0, "shares": 0}],
    "price_per_share": 0,
    "total_amount": 0,
    "post_valuation": null,
    "evidence_text": "原文逐字摘录",
    "data_source": "pdf_disclosed|calculated|inferred",
    "notes": ""
  }]
}

子类型判断规则:
- A1: 有明确的price+shares+amount三字段 → 三者都要提取
- A2: "A、B缴纳的出资款X万元" → 每个投资人的amount留null, notes注明"合计未拆分"
- A3: 关键词含"员工持股平台""股权激励""股份支付" → 标注为员工激励
- A4: 原文含"投后估值""投前估值" → 提取估值数字
- A5: "原股东同比例增资" → 标注非PE/VC事件

价格单位判断:
- "元/股" → price_per_share
- "元/注册资本" → price_per_share (股改前)
- "万元" → total_amount单位万元

关键规则:
1. evidence_text必须是原文逐字摘录，不可概括。
2. 如果原文只给合计金额→单个投资人amount留null，"不能反推"。
3. 如果"拟募集"和"实际收到"不一致→以实际收到（验资报告）为准，拟募集放入notes。
4. 上市公司作为投资人的→标注investor_type="产业资本(CVC)"。
```

### B 型 prompt: 股改提取

```
提取整体变更（股改）事件。识别模式:
- "整体变更设立股份有限公司"
- "按X:X比例折股"
- "经审计净资产X元折为X万股"

输出字段: date, audit_benchmark_date(审计基准日), net_assets(经审计净资产),
conversion_ratio(折股比例), post_shares(折股后总股本), initiators(发起人列表),
evidence_text
```

### D 型 prompt: 股权转让提取

```
提取股权转让事件。子类型判断:
- D1同一控制: "同一股权结构""同一控制下"→关注转让方/受让方关系
- D2代持还原: "股权代持已解除""代持还原"→零对价, traceability=external_required
- D3零对价: "转让价格为0元"→标注原因（架构调整/业绩补偿）
- D4外部转让: 新投资人通过转让进入→有明确对价
- D5批量多对多: 3+个转让方+3+个受让方同时交易→每人一行
- D6间接层面: 转让发生在股东层而非公司层→标注"间接"

输出字段: date, transferor, transferee, shares, amount, price_per_share,
transfer_type(子类型), evidence_text
```

### H 型 prompt: VIE提取（仅影石创新需要）

```
影石创新专属。提取VIE全流程子事件:
H1: 开曼岚锋设立
H2: 香港岚锋设立
H3: 北京WFOE设立
H4: VIE协议签署
H5: 开曼岚锋回购境外投资人股份
H6: 镜像回归(开曼→境内等比例平移)
H7: VIE终止协议签署
H8: 股权出质注销
H9: VIE实体注销

特殊关注: 
- 英文投资人名(EARN ACE=IDG, QM101=启明创投)
- 镜像回归原则: "持股比例保持不变"
```

### F 型 prompt: 资本公积转增提取

```
提取资本公积转增事件。识别模式:
- "每X股转增X股"
- "资本公积转增股本"
- "资本公积金...转增"

关键规则:
1. amount_subscribed=0 (非外部融资)
2. event_context="资本公积转增"
3. shares_subscribed=转增股数
4. 不是外部融资→在notes中明确标注
```

## 四、已知局限

| 局限 | 影响 | 解决方案 |
|------|:--:|------|
| 合并MD p50-64 普遍缺失 | 设立/股改/早期转让约30%事件无原文 | 扩大页码范围至关键小节 ±5页 |

| 英文投资人名 | EARN ACE/QM101/CASREV → LLM识别 | D5型prompt |
