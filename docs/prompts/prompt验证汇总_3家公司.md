## 三、关键发现

### 1. Prompt 质量取决于输入质量

```
三协电机: 10页手动精选原文 → 100%准确
影石创新: 14页VIE+PE合并 → 100%准确
云汉芯城: 17页但p56截断 → 50% (缺流程图文本)
```

**不是 prompt 不行, 是输入的 MD 质量决定了上限。** p56 流程图没转文本 → 7/12 事件丢失。

### 2. 三协电机 v1→v2 的三个致命错误 = 老师问的根因

| v1 错误 | 对应融资行为类型 | 为什么代码会错 |
|------|------|------|
| 合计填入每个投资人 | A2 多主体合计 | 只匹配"出资款X万元", 没判断"两个主体+一个金额" |
| 拟募集≠实际收到 | 公告vs验资差异 | 不知道招股书中"拟"="预计", 验资="实际" |
| 转增误判为增资 | F vs A 语义混淆 | "转增"含"增"→触发A型规则 |

**这些不是代码 bug, 是领域知识缺失。** 每个陷阱背后是招股书写作惯例的一部分。

### 3. 类型级 prompt 一次写对的比例

```
一次写对: A1(100%), E(100%), H(100%), D5(100%), J(100%), B(100%)
需要修复: A2(0%→100%), F(0%→100%), C(正确的但MD不足)
```

7/10 类型第一次就 100%, 只有 A2 和 F 需要迭代。而 A2 和 F 正是三协电机最特殊的两个类型——验证了"最难的类型应该最先修"的策略。
