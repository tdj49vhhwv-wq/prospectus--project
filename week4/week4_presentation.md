## 5. 特殊难点

### 5.1 定向发行合计不分拆（核心难点）

- 2022年定增: "稳正景明、长泽创投缴纳的出资款2,374.40万元"——**一个数字对应两个主体**
- 2023年定增: "盛祎、盛松……等15名认购人缴纳的出资款1,723.09万元"——**一个数字对应15个主体**
- **处理原则**: amount_subscribed 字段留空（填了就是反推），在 notes 中注明"PDF只披露合计"

### 5.2 拟募集 ≠ 实际收到（数据不一致）

- 2023年: 拟募集1,739.32万 vs 实际1,723.09万 → 差异16.23万
- **处理**: 标记"待复核"，不硬凑
- 原因可能是认购人实际缴款与认购额度有微小差异

### 5.3 设立时出资结构缺失

- 招股书p30只写"成立日期 2002年11月7日"，未披露设立出资额
- t0股权结构只有持股比例（62.97%/19.49%是IPO时点），不是设立时点
- **处理**: 需补充《公开转让说明书》（全国股转系统披露）

### 5.4 10转增3.8股的股本变化

- 2023年权益分派导致所有股东持股同比例增加
- 转增后总股本从38,485,000股 → 53,109,300股（增加38%）
- 这是**资本公积转增**事件，非增资事件

### 7.5. LLM 三任务详细展开

#### 任务 1: 拆分"15名认购人"名单

**输入原文**（p32）:
> "公司已收到盛祎、盛松、薛小丽、倪进宽、余方成、吴春扣、陆宇君、戈翔俊、陈都亮、圣利、董雪强、文涛、付荷庆、陈韵和盛月瑶15名认购人缴纳的出资款1,723.09万元。"

**规则为什么失败**:
- 分隔符混合：前13人用"、"，后2人用"和"
- 正则可以按`[、和]`拆分，但无法区分"陈韵"+"盛月瑶" vs "陈韵和"的问题
- 15人共一个金额 1,723.09万 → 单独出资额 PDF 未披露

**LLM 需要做什么**:
1. 将名字列表拆分为15个独立姓名
2. 每个姓名应为2-3个中文字符的合法中文人名
3. 识别"和"在此语境中是连接词（不是人名的一部分）
4. 输出: `["盛祎","盛松","薛小丽","倪进宽","余方成","吴春扣","陆宇君","戈翔俊","陈都亮","圣利","董雪强","文涛","付荷庆","陈韵","盛月瑶"]`
5. 验证: 拆分后数量 = 15（与原文"15名"一致）

**难度**: ⭐ 低。本质是中文姓名分词 + 数量验证。正则 + 简单规则即可覆盖。

#### 任务 2: 判断"拟募集 vs 实际收到"差异

**输入原文**（p32）:
> "拟发行普通股321.50万股，拟募集资金总额为1,739.32万元"
> "公司已收到……缴纳的出资款1,723.09万元"

**数据**:
- 价格 × 数量 = 5.41 × 321.50 = **1,739.315万元**
- 实际收到 = **1,723.09万元**
- 差额 = **16.23万元** (0.93%)

**规则为什么不够**:
- 规则可以算出 1,739 ≠ 1,723，但**不知道这个差异是否需要报告**
- 0.93%差异可能的原因: 四舍五入、部分认购人少缴、验资报告取整
- 规则无法判断是"正常差异可以忽略"还是"提取错误需要复核"

**LLM 需要做什么**:
1. 识别两个金额来自PDF不同段落（发行公告 vs 验资报告）
2. 判断差异性质: 拟募集 ≠ 实际收到是正常的（拟募集是预计，验资是实际），还是数据提取错误
3. 如果是正常差异 → 标记 `data_source: "pdf_disclosed"` + `notes: "拟募集≠实际收到属正常差异，以验资报告为准"`
4. 如果是可疑差异 → 标记 `confidence: "low"` + 放入 `manual_review_queue`

**难度**: ⭐⭐ 中。需要语义理解：理解"拟"和"实际"在招股书语境中的含义。

#### 任务 3: 理解"10转增3.8股"的股本变化语义

**输入原文**（p32）:
> "以股票发行溢价所形成的资本公积向全体股东每10股转增3.80股。本次权益分派……转增1,462.43万股。"

**规则为什么失败**:
- 规则能匹配关键词"资本公积""转增"，但难以理解**语义链**:
  - "每10股转增3.80股" → 转增比例 = 38%
  - "权益分派时股权登记日应分配股数38,485,000股" → 转增前总股本
  - 38,485,000 × 0.38 = 14,624,300 ≈ **1,462.43万股** → 转增后总股本 = 38,485,000 + 14,624,300 = 53,109,300
- 规则需要手动写三步计算逻辑，不同公司比例不同（10转2、10转5等）

**LLM 需要做什么**:
1. 从原文中提取三个关键数字: 转增比例（10转3.8）、转增前股本（38,485,000股）、转增数量（1,462.43万股）
2. 验证: 38,485,000 × 3.8 ÷ 10 = 14,624,300 ✓
3. 生成一个 `subscription_flow` 事件:
   ```json
   {
     "event_context": "资本公积转增",
     "subscription_date": "2023-12-01",
     "shares_subscribed": 1462.43,  // 万股，转增总数
     "notes": "10转增3.80股，转增前总股本38,485,000股，转增后53,109,300股"
   }
   ```
4. 识别此事件的性质: 它不是"外部融资"，而是"内部权益调整"——不影响认缴金额，只影响持股数量
