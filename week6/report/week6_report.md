## 二、各轮投资者分析

### 2.1 投资者类型分布

从 64 个事件中识别的投资人类型：

| 类型 | 数量 | 占比 | 典型代表 |
|------|:----:|:----:|---------|
| 自然人/创始人 | 20 | 31% | 盛祎、曾烨、黄学英、刘靖康 |
| PE/创投基金 | 9 | 14% | 深创投、达晨、东方富海、高瓴 |
| 员工持股平台 | 9 | 14% | 黄山佳捷、三联合伙、共青城泽升 |
| 产业资本 | 4 | 6% | 赛格高技术、力源信息、火炬电子、中科星图 |
| 政府引导基金 | 4 | 6% | 国科瑞华、中小企业基金、金浦临港 |
| 外资基金 | 3 | 5% | EARN ACE、QM101(启明)、IDG |
| 券商直投 | 2 | 3% | 华泰大健康一号、聚贝投资 |
| VC/天使 | 1 | 2% | 丰利财富 |
| 其他(全体股东等) | 12 | 19% | 股改、转增、IPO |

### 2.2 各轮次投资者特征

**设立阶段(E型)**: 全部为自然人或母公司出资，无外部机构。8家公司中6家由2-3名自然人联合设立，友升股份为中美合资（400万美元），星图测控为母公司四方股份控股（60%）。

**早期增资(A1/A2型)**: 产业资本和PE基金为主。云汉芯城2014年引入力源信息（产业）+东方富海（PE），赛分科技2018年引入华泰大健康（券商直投）。此阶段估值较低（4.48-25元/股）。

**中后期增资(A4型)**: 头部PE/政府基金集中进入。赛分科技2021年引入高瓴、国寿疌泉、复星等10家机构（127.24元/股），友升股份2022年引入达晨系6只基金+杉晖等10家（33.63元/股）。

**员工激励(J型)**: 全部为有限合伙企业形式，通常安排在股改前1-2年。价格低于同期外部融资（4.50-23.55元/股 vs 外部22.42-127.24元/股）。

**VIE相关(H型)**: 仅影石创新，涉及IDG、启明(QM101)、迅雷、苏宁等境外知名机构，2018年回归境内后等比例映射。

## 三、共同特征与差异

### 3.1 共同特征

1. **融资节奏**: 所有公司均遵循"设立→早期增资→中后期增资→员工激励→股改→IPO"的标准路径，员工激励集中在股改前1-2年。

2. **估值跃升**: 从设立到IPO前最后一轮，估值增幅在10-100倍之间。赛分科技从6.15元/股（2017员工）到127.24元/股（2021 PE），4年增长20倍。

3. **股改必经**: 8家公司全部经历有限公司→股份有限公司的整体变更（B型），折股比例0.27-1.46不等。

4. **代持普遍**: 8家中5家存在股权代持（三协、赛分、友升、星图、云汉），均在IPO前完成还原。

5. **PE集中进入**: 中后期增资轮通常有5-10家机构同时进入，形成"抱团投资"模式。

### 3.2 差异

1. **VIE结构**: 仅影石创新采用境外VIE架构（开曼→BVI→WFOE→VIE），其余7家均为纯境内架构。VIE搭建和拆除增加了4-5个额外事件。

2. **融资密度**: 云汉芯城12年8轮（平均1.5年/轮），友升股份33年6轮（平均5.5年/轮），反映行业融资节奏差异——电子元器件分销需要更多流动资金。

3. **政府参与度**: 星图测控（中科星图增资）和云汉芯城（国科瑞华/中小企业基金）有明显政府引导基金参与，三协电机和友升股份则完全市场化。

4. **外资参与**: 影石创新（IDG/启明/迅雷）和友升股份（早期美资40%）有外资背景，其余6家为纯内资。

5. **转增规模**: 赛分科技10.5倍转增（3187万→36649万股）远超其他公司，系科创板上市前扩大股本规模的特殊操作。

## 四、可总结的模式

### 模式一：标准PE/VC投资路径

```
设立(自然人) → 天使/早期(产业资本+小PE) → A轮(知名PE) →
B轮(头部PE+政府基金) → 员工激励 → 股改 → IPO
```

适用: 赛分科技、友升股份、黄山谷捷、星图测控

### 模式二：VIE回归路径

```
设立(自然人) → 境外搭建VIE(开曼/BVI/WFOE) → 境外融资(IDG/启明) →
回购+终止VIE → 镜像回归(等比例映射) → 境内增资 → 股改 → IPO
```

适用: 影石创新

### 模式三：产业孵化路径

```
母公司/合资设立 → 内部代持调整 → 引入产业投资者 →
员工激励 → 股改 → IPO
```

适用: 云汉芯城（力源信息→深创投→国科瑞华）、星图测控（四方股份→中科星图）

### 模式四：北交所精简路径

```
设立(自然人) → 1-2次定增(PE/员工) → 股改 → 北交所IPO
```

适用: 三协电机、星图测控（轮次少、周期短、估值低）
