# 融资事件类型编码映射表

> Pipeline 代码用中文名，Final 报告用缩写，本文档建立双向映射。

| 缩写 | 中文名 | 说明 |
|:----:|--------|------|
| E | 设立 | 公司成立/注册 |
| A:A1 | 增资(早期PE/VC) | 早期外部融资，1-2家机构 |
| A:A2 | 增资(多主体合计) | 多个主体同时进入，仅披露合计金额 |
| A:A3 | 增资(员工/混合) | 员工+外部投资人混合增资 |
| A:A4 | 增资(中后期) | 中后期融资，5-10家机构抱团 |
| A:A6 | 增资(境外) | 境外架构下的融资（如VIE） |
| B | 股改 | 有限公司→股份有限公司整体变更 |
| C | 增资+转让(复合) | 同一事件包含增资和股权转让 |
| D:D1 | 股权转让(同一控制) | 同一控制下转让，通常零对价 |
| D:D2 | 股权转让(代持还原) | 股权代持解除/还原 |
| D:D3 | 股权转让(零对价) | 非同一控制的零对价转让 |
| D:D4 | 股权转让(市场价) | 市场化定价转让 |
| D:D5 | 股权转让(批量) | 多对多批量转让 |
| D:D6 | 股权转让(原价退出) | 按原投资价退出 |
| F | 资本公积转增 | 资本公积转增股本，非外部融资 |
| G | 吸收合并 | 母子公司吸收合并 |
| H:H1-H9 | VIE事件 | VIE搭建/融资/回归/解除（9子事件） |
| I | IPO | 首次公开发行 |
| J | 员工激励 | 员工持股平台增资/股权激励 |

## Pipeline 事件类型 → 缩写

| Pipeline event_context | 对应缩写 |
|------------------------|:--------:|
| 设立 | E |
| 增资 | A:A1 ~ A:A6 |
| 资本公积转增 | F |
| 股改 | B |
| 员工激励 | J |
| 境外融资 | A:A6 |
| 镜像回归+增资 | A:A6 |
| 增资+转让 | C |
