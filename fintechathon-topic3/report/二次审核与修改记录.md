# 二次审核与修改记录（工作材料，不随初赛提交）

审核日期：2026年10月11日。当前版本已经重建PDF、Word、五张中文图和结果工作簿；旧阶段分析稿作为历史过程材料保留，正式阅读以report目录当前报告为准。

## 本轮实质改进

1. 研究主线改为“信息能否量化—是否有效—是否值得使用”，把指标、独立测试、固定预算和产品反馈串成可复验的证据链。
2. 重核12项描述性检验：Holm校正后均分和价格主题的p值为0.0065和0.0487；评分变化为0.0538，未按0.05显著。报告区分描述差异、预测增量和因果关系。
3. 新增六模型的日期限制诊断，固定原测试预测，不重新训练、挑参数或改主模型。只比较同年份停业—营业配对，共260对；增强树AUC从总体0.631变为0.488。2017年107家只有2家停业，树AUC为0.481，主模型0.738；事件不足，不能将主模型子组高分当作可靠优势。全部六模型结果均公开，避免只报告有利子组。
4. 将商业建议具体化：每期核查净价值=k×(p×v−c)−F；同预算相对低评分策略的增量价值=(命中差)×v−新增固定成本。p必须来自未来“可行动风险”确认，不能拿历史停业命中率代替。未杜撰金额、损失降低或商业收益。
5. 设计待执行的流水融合试点：统一月末观测、之后90天经营标签、单独的信用标签、后续月份和新地区留出测试、随机抽查对照、独立人工确认。只有增量区间下界及净价值均通过才扩大使用。
6. 第三轮补核覆盖率：纳入674/1361家餐饮商户（49.52%），只纳入123/318家停业主体（38.68%）。被排除687家中195家停业（28.38%），不能将无足够公开数据的主体视为低风险。修正了旧稿“长期无评论主体被排除”的不准确表述：筛选按各自最后评论锚点计算，并非统一日历时点的评论停更筛选。
7. 补核概率评分：拟合期98/539的停业比例作常数预测，测试Brier为0.150903；主模型0.166265、增强树0.151878。Brier衡量概率预测均方误差，不能单独分离校准与辨别能力；当前模型未在该评分上优于常数，不宜把分数展示为可信概率。
8. 拟合期均分与低分占比Spearman=-0.9335，近期与前期评论数为0.7359，解释回归系数时须考虑相关性。补充核实失访、标签成熟、随机对照的适用范围及反馈回退方案，见《验证闭环执行方案》。

## 审核结论

现有材料能支持公开口碑画像与历史营业状态识别的可行性研究。主模型增量不稳定，较高树模型测试表现未在日期限制诊断中保持。当前证据不足以宣称前瞻预警、信用违约预测、深圳落地有效或商业回报成立。

本轮不再用已看过的测试集寻找更高分模型；后续改模型需要新的留出样本。追加审计属于事后诊断，不能包装成事先预注册或独立复验。新指标的定义与结果见outputs/additional_robustness.csv及其说明JSON；复现脚本为scripts/review_evidence.py。
