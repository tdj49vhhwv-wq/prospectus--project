## 报告主线

报告保留全部预设模型，区分验证集选出的主模型与探索性树模型比较。结论是公开信息可构建经营画像，但主分析增益不稳定，树模型复核改善的区间仍包含无改善；数据只能支持历史营业状态识别，不支持提前停业预测或信用违约预测。

最新版还包括覆盖率、未纳入组状态、指标相关性及概率评分审计，并把结论对应到可观测性分流、人工核查、未来流水融合试点和验收回退。`验证闭环执行方案.md`为内部后续计划，不随初赛提交，不代表已执行实验。

## 重建与检查

从分析目录运行（Python依赖见`requirements-tested.txt`，另外需要XeLaTeX）：

```bash
cd /workspace/prospectus--project/fintechathon-topic3
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-tested.txt
OMP_NUM_THREADS=2 MPLCONFIGDIR="$PWD/.mpl-cache" .venv/bin/python scripts/build_submission.py
.venv/bin/python scripts/validate_submission.py
```

填写正式信息时，把生成命令改为：

```bash
.venv/bin/python scripts/build_submission.py --team-name '285小组' --group-id '285'
.venv/bin/python scripts/validate_submission.py
```

字体从固定公开Git提交下载并校验SHA256；许可见`fonts/COPYING`，含文档嵌入例外条款。字体原始来源为https://github.com/Yixf-Self/fandol-fonts/tree/b93300821373d3092e378e57ae22ecb8e9082c62 ，原始字形文件未随报告包分发，报告中的嵌入字体未修改。
