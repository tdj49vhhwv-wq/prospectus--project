# 验证闭环执行方案（后续试点设计，不是已完成实验）

本文已完成的是历史公开评论的指标构建、营业状态识别、固定预算模拟和事后偏差审计。以下方案用于补齐真实流水、未来标签和商业价值证据；不应将其描述为当前报告已有的实验成果。

## 1. 观察对象与时间边界

先取得合法数据使用范围和商户授权，确认经营主体规模、主体匹配和连锁关系。以统一月末t观察同一主体，只用t及之前可获得的公开信息和授权流水；锁定取数版本、更新时点、指标计算和主体匹配规则。

每个训练标签必须已成熟：其观察日加90天不晚于测试观察日。不能用未来评论、后补营业状态或未成熟的90天结果拟合。保留后续月份及新地区测试；地区外样本注意连锁关联。重复月度商户的不确定性按主体分组估计，避免将同一主体的多个月份当作独立样本。

公开信息不足的商户进入独立队列，不填成零风险、不与已覆盖商户直接比较分数。公布全体目标商户数、成功匹配数、指标可计算数和完成核实数，以全体目标商户而非最终纳入样本计算覆盖率。

## 2. 标签与独立核实

- 停业：观察日之后90天内首次发生并由电话或实地核实，记录发生日期、核实日期和持续情况。标签规则及持续天数门槛应在试点前锁定。
- 搬迁／主动退出：独立分类，不能自动等同财务困难。
- 经营困难：记录经核实的困难事件和证据（例如无法支付应付经营支出）；事先锁定事件清单和判断口径，不能仅靠差评或无评论判断。
- 信用逾期：仅在授权贷款表现中定义，单独分析，不用停业替代。
- 无法联系、未成熟、证据冲突：记为未知或待核实，不记为正常营业；报告其比例及敏感性分析。

复核人员先依据独立证据确认状态，再查看模型原因，记录信息来源和分歧复审。若模型引发干预，记录干预时点；未来标签与处置影响分开分析，避免把干预后未发生事件简单算成模型误报。

## 3. 锁定基线、预算与对照

同一批主体比较真实流水基线、流水＋公开指标和低评分筛选；固定每期10%核查预算和主评价指标，先用训练／验证期确定模型，测试后不再选优。

试点保留随机核查对照，分层覆盖信息充分和信息不足的主体。模型名单可评价命中率；全量漏报率须依赖充分的独立标签或带已知抽样概率的随机核查，不能只给模型挑出的商户贴标签后宣称召回率提高。

处置收益是另一项问题。若要声称风险损失下降，应建立可比对照并记录实际干预成本、损失和回收，不能将“多发现若干停业商户”直接换算成节省金额。

## 4. 结果与验收

预先锁定主指标为同预算有效风险命中率差，并报告配对不确定性；辅以AP、覆盖率、各地区表现、漏报估计和概率误差。解释误报、失访及标签成熟率。评价概率用途时应在拟合期校准，再在保留测试验证；不能在测试集上校准并汇报同一测试效果。

记k为复核数量、p为前瞻可行动风险命中率、v为经对照核实的每次有效发现净收益、c为单家核查成本、F为期间固定成本，绝对净价值为k×(p×v−c)−F。同预算相对基线的增量价值为(命中差)×v−新增固定成本。没有真实成本及处置价值时只报告盈亏条件，不报告实现的收益。

只有预设增量区间下界大于0、净价值大于0、覆盖和核实质量达标，并通过时间外／地区外复验，才考虑扩大排序使用。样本量应根据最低可接受命中率差、试点事件率和抽样设计估算，不能承诺一个未计算的最低样本数。

## 5. 回流与回退

每期记录观察时间、数据可用性、模型版本、触发指标、入选策略、抽样概率、核实状态、事件日期、核查耗时、处置及后续结果。每月监测覆盖率、指标分布、命中率、误报、失访和实际成本。

覆盖下降或效果不足时暂停排序，保留公开画像展示和人工补资料；用已成熟的新数据重新开发，并以新的留出期复验。原测试集只作为审计记录，不重复用于寻找更高分模型。
